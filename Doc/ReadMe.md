## SPI总线和SPI外设
### SPI特性
    - 基于三条线的全双工同步传输
    - 基于双线的单工同步传输
    - 支持8位或16位传输帧格式: 数据寄存器是16位, 同时用于发送和接收
### SPI flash
1. **读->修改->写入**
    - 由于flash写入前需要进行擦除(按扇区)
    - 安全写入方法: 把扇区内容读取到内存中, 对需要修改的数据进行修改, 擦除扇区, 把内存数据重新写入扇区
2. **flash时许问题**
    - 对于有些flash, 命令是存在时序限制的, 比如写入命令, 命令+写入数据, 必须在一个事务中完成, 否则就会命令执行失败的情况
