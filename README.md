# MCU
STM32，GD32，FreeRTOS，RT-Thread

## 仓库基本信息
1. **仓库地址**: https://github.com/Just4Passion/MCU.git
2. **仓库分支总览**
    - main
        - 功能: 介绍各个分支的功能和作用
    - DY_STM32F407
        - 功能: 基于野火霸天虎开发板的裸机MCU开发
    - FreeRTOS_GD32F407
        - 功能：基于GD32F407移植FreeRTOS
    - RT-Thread_GD32F407
        - 功能：基于GD32F407移植RT-Thread
    - MyOS
        - 功能：基于《ARM Cortex-M3/M4权威指南》的指导，在GD32F303平台上实现简易OS
